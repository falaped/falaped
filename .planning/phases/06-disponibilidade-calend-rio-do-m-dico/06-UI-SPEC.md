## Spacing Scale

Declared values (all multiples of 4). Matches the repo's `flex flex-col gap-6` / `p-6`/`p-8` page convention (pediatric-dashboard-design skill).

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px | Gap between a slot label and its dot; inline icon gaps |
| sm | 8px | Compact spacing inside a slot cell; badge padding |
| md | 16px | Default spacing between controls (band duration selector, toolbar buttons) |
| lg | 24px | Page section gap (`gap-6`), card padding |
| xl | 32px | Layout gaps between the availability editor and its side controls (`p-8`) |
| 2xl | 48px | Major section breaks (editor block vs. views block) |
| 3xl | 64px | Page-level top/bottom breathing room |

**Grid density exceptions (agenda-specific, D-03 30-min step):**
- **Time-row height:** `1.5rem` (24px) per 30-min slot row in day/week grid — matches RESEARCH.md Pattern 3 (`gridTemplateRows: 2.5rem repeat(N, 1.5rem)`). This is a fixed layout dimension, not a spacing token; it is intentionally 24px to keep a full working day visible without scroll thrash.
- **Header row height:** `2.5rem` (40px) for the day-of-week header and the availability-editor column header.
- **Time gutter width:** `4rem` (64px) fixed column for hour labels (`gridTemplateColumns: 4rem repeat(N, minmax(0,1fr))`).
- **Minimum tap target:** interactive availability cells and view-switch controls must be ≥ 44px in at least one axis for touch; the 30-min cell (full column width × 24px) satisfies width — pair with generous hit area, do not shrink the clickable region below the visual cell.

Exceptions: the three grid dimensions above (24px row / 40px header / 64px gutter). All other spacing uses the 4-multiple scale.

## Typography

Consumes existing dashboard type conventions (pediatric-dashboard-design skill: h1 `text-2xl font-semibold tracking-tight`, description `text-sm text-muted-foreground`). Exactly 4 sizes, 2 weights.

| Role | Size | Weight | Line Height | Applied to |
|------|------|--------|-------------|------------|
| Display / Page title | 24px (`text-2xl`) | 600 (`font-semibold`) | 1.2 | Page h1 ("Agenda") |
| Heading / Section | 20px (`text-xl`) | 600 (`font-semibold`) | 1.2 | View-block headings, editor block title, dialog titles |
| Body | 16px (`text-base`) | 400 (`font-normal`) | 1.5 | Slot times, band range labels, exception list rows, descriptions |
| Label / Meta | 14px (`text-sm`) | 400 (`font-normal`) | 1.5 | Time gutter labels, day-of-week headers, muted helper text, month-cell slot count |

**Weights:** exactly two — regular (400) and semibold (600). No medium/bold elsewhere. Grid time labels use 400 in `text-muted-foreground`; the current-view label and today marker may use 600 for emphasis (still within the two-weight set).

**Line height:** 1.5 for body/label; 1.2 for headings/display (matches recommended defaults and existing pages).

## Color

60/30/10 split built entirely on existing oklch tokens (`app/globals.css`). The primary is a soft pediatric blue (`oklch(0.7603 0.0916 255.41)`) — this is the ONLY accent hue and must stay reserved.

| Role | Token | Value (light) | Usage |
|------|-------|---------------|-------|
| Dominant (60%) | `--background` | `oklch(0.985 0 0)` | Page background, agenda grid empty area, month grid |
| Secondary (30%) | `--card` / `--secondary` / `--muted` | `oklch(1 0 0)` / `oklch(0.967 0.001 286)` / `oklch(0.97 0 0)` | Cards wrapping editor & views, day-of-week header band, time gutter, unavailable/lunch-gap cells (`bg-muted`) |
| Accent (10%) | `--primary` | `oklch(0.7603 0.0916 255.41)` | See reserved list below |
| Destructive | `--destructive` | `oklch(0.58 0.22 27)` | Delete-exception action + its confirmation only |

**Accent (primary blue) reserved for — explicit, closed list:**
1. Selected/painted available cells in the weekly availability editor (D-01) — fill `bg-primary/15` with `border-primary` or a solid `bg-primary/20`; the "on" state of a 30-min block.
2. Free-slot cells rendered in the day/week agenda view (a slot the doctor offers) — subtle `bg-primary/10` fill with `text-foreground` label.
3. The single primary CTA button per surface ("Salvar disponibilidade").
4. The active view tab (dia/semana/mês) and the "hoje"/today column marker.
5. Month-view "atende" day indicator dot (D-07) — a small `bg-primary` dot; days with no availability show no dot (muted).

**NOT accent (must use neutral/secondary tokens):** grid lines/borders (`border-border`), time labels and day headers (`text-muted-foreground`), lunch-gap and unavailable cells (`bg-muted`), secondary buttons (view navigation prev/next → `variant="outline"` or `ghost`), exception rows.

**Semantic state colors (functional, not counted in the 10% accent budget):**
- **Folga / dia bloqueado** (full-day exception, D-04): neutral muted treatment (`bg-muted text-muted-foreground`) with a strike or "Folga" badge — NOT destructive red (a day off is not an error).
- **Destructive red** is used exclusively for the "Excluir exceção" action and its confirmation.

### Empty states (dashed-border pattern from design skill: `rounded-xl border border-dashed p-8 text-center`)

| Surface | Heading | Body + next step |

| Availability editor — nothing configured yet | Nenhum horário configurado. | Selecione os blocos na grade abaixo para definir quando você atende. |

### Loading states

- Use existing `Skeleton` primitive. Agenda grid loading: render the grid frame (gutter + headers) with skeleton blocks in the slot area. Editor loading: skeleton over the weekly grid. Do NOT show a bare spinner over an empty page.

### Error states

| Situation | Copy (problem + path forward) |
|-----------|-------------------------------|
| Save availability failed | Não foi possível salvar a disponibilidade. Verifique sua conexão e tente novamente. |
| Load agenda failed | Não foi possível carregar a agenda. Atualize a página para tentar novamente. |
| Create/delete exception failed | Não foi possível salvar a folga. Tente novamente. |
| Invalid band (validation, from Zod → PT-BR via `lib/zod-error-message.ts`) | Field-level message below the control, `text-destructive text-sm`. E.g. "A faixa deve começar e terminar em múltiplos de 30 minutos." / "O horário final deve ser maior que o inicial." |

Action outcomes surface via `sonner` toast (success + error), consistent with the repo.

### Destructive actions

| Action | Confirmation approach |
|--------|-----------------------|
| Excluir exceção (folga) | `AlertDialog`: title "Excluir folga?", body "A folga de {data} será removida e o dia voltará à disponibilidade recorrente. Esta ação não pode ser desfeita.", confirm button "Excluir" (`variant="destructive"`), cancel "Cancelar". |

No other destructive actions in this phase. Editing/replacing the recurring grid is a save (upsert), not a destructive confirm — but if a save would remove previously-painted blocks, keep it a plain "Salvar disponibilidade" (non-destructive); no confirm required.

## Key Layout & Interaction Contract (phase-specific)

> These resolve the three open questions the technical researcher flagged (all under "Claude's Discretion" in CONTEXT.md), respecting the 30-min step (D-03) and all locked decisions. The planner/executor treat these as the contract.

### Visible hour range & row density
- **Default visible range: 06:00–22:00** (32 rows of 30 min). Rationale: covers a pediatric clinic day with headroom; matches RESEARCH.md Pattern 3 example. Rows outside a configured band render as neutral `bg-muted`/empty.
- If a doctor's configured band falls outside 06:00–22:00, the grid MUST auto-extend its visible range to include the full band (never clip a saved band). Range floor 00:00, ceiling 24:00.
- Row height fixed at 24px (see Spacing exceptions); hour labels every 60 min in the gutter (`06:00`, `07:00`...), with a lighter half-hour divider line at `:30`.

### Availability editor interaction model (D-01)
- **Click-to-toggle a 30-min cell** is the required baseline: click an empty cell → becomes available (accent); click an available cell → becomes empty. This is the simplest correct model and the one the contract mandates for this phase.
- **Drag-to-paint is an optional enhancement**, not required. If implemented, it must reuse the same toggle semantics (drag sets a run of cells to the same target state). Do not block the phase on drag support.
- Contiguous painted cells in a day form a **band** (D-02); a lunch gap of empty cells splits a day into multiple bands automatically. The editor derives bands from the painted grid — the doctor never fills a row-based form.
- **Week layout:** Segunda→Domingo columns, left-to-right (week starts Monday, D-11). Seven day columns + time gutter.

### Per-band slot duration (D-09) — display without clutter
- Each contiguous band shows a **compact inline duration control anchored to the band's top edge**: a small `Select` (or `Popover` trigger) reading e.g. "30 min" / "20 min", using `text-sm`. Options in 5-min steps or a sensible preset list (10/15/20/30/45/60), default 30 min.
- The control appears only on the band it governs (one per contiguous band), NOT one per 30-min cell — this is the anti-clutter rule. When a band is a single 30-min cell, the control still applies to that band.
- The band's fill visually groups its cells (shared accent fill + a subtle outer border around the contiguous run) so the doctor reads "this block, this duration" at a glance.

### Three views (D-06/D-07/D-08)
- **View switcher:** `Tabs` primitive, order Dia · Semana · Mês, default **Semana**. Active tab uses accent.
- **Day & Week (D-08):** custom Tailwind CSS grid (NO calendar lib). Time gutter (`sticky left-0`) + day header (`sticky top-0`). Free slots rendered as accent cells positioned by `grid-column`/`grid-row` from the 30-min index. Lunch gaps / unavailable time = neutral. Today column gets an accent top marker.
- **Month (D-07):** lightweight month grid (custom, Monday-first). Each day cell shows only: an "atende" accent dot when `hasAvailability`, plus the free-slot count as small muted `text-sm` (e.g. "8 livres"); "folga"/no-availability days show muted styling and no dot. **Never render real slot times inside a month cell.** Clicking a day may switch to Day view for that date (optional, non-blocking).
- **Exception date picker:** the existing `components/ui/calendar.tsx` (react-day-picker) is reused ONLY as the date input inside the "Adicionar folga" flow (`Dialog` or `Sheet`), with a toggle for "Dia inteiro" vs. "Período" (partial band, D-04). It is NOT used to render the agenda grid.

### Responsiveness
- Week grid is horizontally scrollable on narrow viewports (min column width via `minmax`); the time gutter stays `sticky left-0`. On mobile, default to **Dia** view is acceptable but not required — Semana remains the app default (D-06).
