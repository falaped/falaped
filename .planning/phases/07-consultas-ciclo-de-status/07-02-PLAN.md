## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → Server Action | Untrusted input (patient_id, starts_at, ends_at, status from/to); Zod safeParse at the boundary |
| Server Action → module → Postgres | profile_id stamped from the authenticated profile; RLS + double .eq enforce ownership; exclusion constraint enforces the invariant |
| DB error → client | PostgrestError never returned raw; 23P01 mapped to friendly PT-BR result union |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-04 | Elevation of Privilege | IDOR — creating/mutating another doctor's appointment | high | mitigate | profile_id stamped server-side from `profile.id` (never from client); every mutation double-scoped `.eq("profile_id", profile.id).eq("id", id)`; RLS backstop from Plan 01 |
| T-07-05 | Elevation of Privilege | subscription-gate bypass via direct PostgREST | high | mitigate | paid gate (`profile.status === "paid"`) enforced in every action (RLS only enforces `authenticated`, not `paid`) |
| T-07-06 | Information Disclosure | raw Postgres error leaking to UI (23P01, details/hint) | medium | mitigate | catch narrow (`error: unknown`), SQLSTATE mapped to PT-BR copy; never return error.message/details/hint |
| T-07-07 | Tampering | illegal status transition (e.g. reopen canceled) / concurrent transition overwrite | high | mitigate | isLegalTransition guard in the action + compare-and-set `.eq("status", from)` in the module (enum restricts values; legality is app rule) |
| T-07-08 | Tampering | booking outside availability (forced slot, D-02) | medium | mitigate | server-side slot-free check via expandAvailability before insert; exclusion constraint is the final backstop for the concurrent race (TOCTOU accepted, DB arbitrates) |
| T-07-SC | Tampering | npm/pip/cargo installs | high | accept | No new packages this phase (RESEARCH Package Legitimacy Audit: none new) |
